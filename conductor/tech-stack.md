# Tech Stack

## Languages
- **Nushell (`.nu`):** Primary language for CLI scripting and logic.
- **AWK (`.awk`):** Used for efficient text processing and filtering of genomic datasets.
- **Python (`.py`):** Used for data visualization and complex analysis scripts.

## External Tools & CLI
- **NCBI Datasets CLI:** For downloading genomic data and metadata from NCBI.
- **count-fasta-rs:** A fast Rust-based tool for counting FASTA sequences.
- **uv:** A fast Python package manager for managing visual analytics dependencies.

## Key Libraries
- **Matplotlib/Seaborn:** Used for generating dataset statistics plots.
- **Nushell Standard Library:** Leveraged for script-based automation and file handling.

## Development Environment
- **Git:** Version control for the project.
- **Conductor:** Project management and orchestration framework.
