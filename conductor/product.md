# Product Definition

## Initial Concept
A tool to download genomic data using NCBI Datasets command-line tools and other utilities.

## Target Users
The primary users are **Bioinformaticians** and **DevOps/Data Engineers** who need to reliably retrieve and process large-scale genomic datasets from NCBI and EBI for downstream analysis or automated pipelines.

## Core Features
- **Data Retrieval:** Efficiently download genomes and annotations from NCBI and EBI using command-line tools.
- **Data Processing:** Filter and process downloaded files using Nushell and AWK scripts for seamless integration into bioinformatics workflows.
- **CLI Interface:** A clear and functional command-line interface for managing download tasks.

## Success Metrics
The project's success is defined by its **Reliability**. It must ensure that downloads are consistent, reproducible, and robust against network issues or API limitations, providing a dependable source of genomic data for researchers and automated systems.
